# 🚑 Healthcare Operations Simulation Model

A simulation model designed to analyze, optimize, and improve patient flow, resource allocation, and waiting times within healthcare facilities.

## 🛠️ Tools & Technologies
- **Simulation Platform:** AnyLogic
- **Focus Areas:** Healthcare Operations, Queueing Theory, Resource Optimization, Process Flow Visualization

## 📊 Project Highlights
- Modelled patient arrival rates, triage processes, and treatment queue priorities.
- Simulated resource pool capacity (doctors, nurses, bed availability) to identify operational bottlenecks.
- Integrated statistical dashboards to measure average wait times and system throughput.
